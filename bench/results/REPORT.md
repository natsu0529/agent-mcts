### Same budget and generated tests: the search against best-of-N

Best-of-N spends the same episode budget on first attempts under the root, with no revisions. They are not independent samples: like the search's first attempts, each is told the approaches of the ones before it and asked to take a different one.
Each pair is the `generated` run and the baseline run of the same task and
repeat, with the same model and budget, both scored on the same generated test
file (checked by hash). Difference: search minus baseline in hidden-test points,
with a 95% t interval; p: two-sided sign test. Oracle: the best best-of-N attempt
by hidden score. Cost leaves out writing the tests, which the pair shares.

### Same budget and generated tests: the search against sequential

Sequential spends it on one chain: each attempt revises the one before it with its failing test output, without a tree, and the best attempt along the chain by reward is returned.
Each pair is the `generated` run and the baseline run of the same task and
repeat, with the same model and budget, both scored on the same generated test
file (checked by hash). Difference: search minus baseline in hidden-test points,
with a 95% t interval; p: two-sided sign test. Oracle: the best sequential attempt
by hidden score. Cost leaves out writing the tests, which the pair shares.

### Same budget and generated tests: the search against best-of-N

Best-of-N spends the same episode budget on first attempts under the root, with no revisions. They are not independent samples: like the search's first attempts, each is told the approaches of the ones before it and asked to take a different one.
Each pair is the `generated` run and the baseline run of the same task and
repeat, with the same model and budget, both scored on the same generated test
file (checked by hash). Difference: search minus baseline in hidden-test points,
with a 95% t interval; p: two-sided sign test. Oracle: the best best-of-N attempt
by hidden score. Cost leaves out writing the tests, which the pair shares.

|---|---|---|---|---|---|---|---|---|---|---|---|
